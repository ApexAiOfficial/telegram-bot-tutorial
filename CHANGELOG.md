# Changelog

All notable changes to this project will be documented in this file.  Dates are in UTC.

## [0.1.0] - 2026-06-16

### Added

- Initial public release of the **Telegram Bot Tutorial** repository.
- Scaffolded repository structure with top‑level docs, diagrams, examples, deployment guides and QA checklist.
- Added documentation chapters covering absolute‑zero setup, BotFather and token safety, Bot API fundamentals, backend reality, polling vs. webhooks, commands and handlers, keyboards and callbacks, state and persistence, security baseline, hosting and deployment, capability map, glossary and troubleshooting.
- Added seven Mermaid diagrams illustrating the update lifecycle, polling versus webhooks, handler routing, conversation state, project structure, deployment decision tree and webhook diagnostics.
- Added twelve runnable example bots demonstrating each stage from an echo bot to a capstone project.
- Added deployment guides for Render (canonical), Railway, DigitalOcean App Platform and a generic VPS.
- Added security checklist and responsible‑use statement.
- Added revalidation policy and snapshot files.
- Added smoke‑test checklist for all examples.
